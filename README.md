# TRACE Boardviewer website

Source of https://trace-boardviewer.github.io/, the website of [TRACE Boardviewer](https://github.com/trace-boardviewer/trace-boardviewer), the free, open-source boardviewer for electronics repair.

The site is plain HTML, CSS and a little JavaScript in `site/`, with no build step. GitHub Actions publishes it to GitHub Pages on every push to `main` that touches `site/`.

Bug reports and questions about the app belong in the [app repository](https://github.com/trace-boardviewer/trace-boardviewer/issues).
