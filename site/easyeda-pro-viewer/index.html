Open EasyEDA Pro V3 boards in TRACE

Updated: 13 October 2026 · TRACE 1.3.3

Use TRACE to inspect an EasyEDA Pro PCB project without opening it in a design editor. The guide below helps you choose the right project file, understand what appears on the board, and pair it with the documents you use during repair.

Download TRACE 1.3.3Exact format support

Which EasyEDA Pro file should you open?

  • EasyEDA Pro V3 project: choose the .epro2 archive itself. TRACE 1.3.3 can select this extension and reads a V3 project when it contains a PCB document with placed components. See the 1.3.3 release notes for the V3 reader changes and named refusal behavior.
  • Earlier Pro project or backup: choose the .epro project archive, or the ZIP backup made by the EasyEDA client. The archive needs its project description and PCB/FOOTPRINT entries together.
  • Bare .epcb document: TRACE can show placed component positions, but this file has no footprints, pads or nets. Open the project archive if you need those details.

Press Ctrl+O (Cmd+O on macOS) and select the project archive, or drag it into TRACE. The reader checks file contents as well as the extension. If it recognizes a project it cannot read, the import message names the reason instead of treating it as an unrelated file.

What the board view contains

For a supported project, TRACE reads placed components, their pads, pad-to-net assignments and the board outline. Search a reference, value or net with Ctrl+F, select a net to highlight its connected pins, and use the board view to locate a part. This is a viewer: it does not edit or convert the EasyEDA project.

Check the import notice before relying on geometry. Tracks, vias, copper pours and text are not read. Oval, polygon and n-gon pads are drawn as bounding rectangles; footprint pad overrides are ignored and disclosed. A bare .epcb has no pads or nets. For bottom-side parts, TRACE applies the EasyEDA Pro mirror-and-rotation rule; the 1.3.3 release notes describe the corrected placement at every angle. Import notes record the real-file evidence: the transform is confirmed at 0°, 90°, 180° and 270°, while other angles have not been checked against real files. Verify pad positions before probing.

Validation covers eight open-licence EasyEDA Pro projects. The checked top-side pad positions agree with same-net routed tracks. This evidence covers those files, not every EasyEDA Pro project or every writer version.

Files TRACE identifies but refuses

  • .eprj and .elib offline SQLite databases are not board archives. Open the project in EasyEDA Pro and export an .epro project archive.
  • A V3 project log without a PCB document containing components has no board to display. TRACE says so in the import message.
  • A footprint by itself has no board placement; a panel or copper-pour result is not treated as a board. Unsupported or damaged records are refused with a reason.

Pair the board with its schematic and PDFs

EasyEDA Pro's native schematic is not a native schematic format in TRACE. For a searchable board-and-reference workflow, attach a supported KiCad, EAGLE or Altium schematic through the Schematic or Documents tab. You can also attach schematic PDFs and datasheets in Documents, search their text, and keep those pages beside the board. PDF text search does not turn a PDF into an electrical netlist.

  1. Open the project archive and review the import notice for approximations or skipped content.
  2. Use Ctrl+F to find a component reference or net, then select it to locate the board object.
  3. Attach a supported schematic and/or PDF datasheet in Documents. Search for the same reference or signal name across the board and attached documents.
  4. Keep repair notes on a selected component or pin if useful. TRACE keeps the project files unchanged.

Offline use and platforms

Opening and reading the project is local; the board archive is not uploaded for conversion. The app has separate optional network features, described in Getting started. TRACE 1.3.3 is available for Windows x64. macOS on Apple silicon and Linux x86-64 remain experimental builds.
