What is a boardviewer?

A boardviewer shows where every part, pin and net sits on a printed circuit board, so you can go from a fault on the schematic to the exact pad to probe. TRACE is a free, open-source boardviewer that keeps the board, its schematic and its PDF datasheets in one window and searches all of them at once. It opens .brd files (EAGLE; TestLink/Landrex and TOPTEST in draft), EAGLE boards and schematics, .bvr boardviews, GenCAD .cad/.gcd and KiCad boards and schematics. New to it? The getting started guide walks through a first repair session. Coming from OpenBoardView or FlexBV? See the honest comparison.

What it does

  • Board: search by reference, value, package or net; net highlighting; pin and part inspection; top and mirrored bottom; zoom, pan, rotate; two-point measurement in mm.
  • Schematic: KiCad and EAGLE schematics with connectivity; exact board↔schematic matching; unmatched or ambiguous parts are listed, never guessed.
  • Documents: offline PDF viewer with text search and page notes; PNG/JPEG/WebP/SVG images with calibrated measurement; documents are remembered per board.
  • Notes: per part or pin, with measured voltage/resistance; they follow the board file by content hash and survive restarts.
  • Private: your boards and files never leave your computer; no account, no telemetry; board files are read without modification; encrypted FZ/CAE needs your own key. The only network request is an optional update check to github.com that you can turn off in Settings.
  • Interface: English, French, German, Hungarian, Italian, Polish, Slovak, Ukrainian; dark/light; Workshop and Focus layouts. Ctrl+O open, Ctrl+F search, F fit, R rotate, M measure.

All releases and checksums

macOS — experimental

Experimental build for Apple silicon Macs only (M1 or later), unsigned, built on a GitHub macOS runner and validated on an Apple M3 MacBook Air. macOS blocks an unsigned app until you allow it once: right-click the app and choose Open, or clear the quarantine flag in Terminal:

xattr -dr com.apple.quarantine "/Applications/TRACE Boardviewer.app"

Intel Macs are not supported. Use at your own risk and tell us what you see.

Linux x86-64 — experimental

Two packages of the same build. They are built and smoke-tested automatically on Ubuntu 24.04 and have not been tested on a desktop Linux machine yet. Neither is signed: check the SHA-256 in a terminal in the download folder before you install or run it.

Ubuntu 24.04 or newer, Debian 12 or newer: .deb (recommended)

TRACE-Boardviewer-1.3.0-linux-amd64.deb

SHA-256 bc41f881664a4c9e21f919b3c0073a03cd4d8d7a49fb367ba5419e570e334676106.9 MB

sha256sum TRACE-Boardviewer-1.3.0-linux-amd64.deb
sudo apt install ./TRACE-Boardviewer-1.3.0-linux-amd64.deb

Installs to /opt and adds an AppArmor profile, so the Chromium sandbox stays on under Ubuntu's user-namespace restriction. Start it from the application menu or with trace-boardviewer. Remove it with sudo apt remove trace-boardviewer; your settings and notes stay.

Questions

Does it send my boards anywhere?

No. Boards, schematics and notes stay on your computer; there is no account and no telemetry. The only network request TRACE makes is an optional update check to github.com when it starts (nothing about you or your files is sent, and you can turn it off in Settings). Updates are never installed automatically: if a newer version exists you get a link to the download page. The window itself runs under a content security policy that allows no remote connections.

My BRD / BDV / FZ does not open.

Check the table above; some families are still draft. Open an issue with the family, file size and the exact diagnostic — never upload a file you may not share.

Is there a Linux version?

Yes, as an experimental build: a .deb for Ubuntu and Debian and a portable AppImage, both for x86-64. They are built and smoke-tested automatically on Ubuntu 24.04 and have not been tested on a desktop Linux machine yet, so please tell us how they work on your distribution. See the Linux downloads and the Linux page.

Where do I get board files?

TRACE does not include or link to board files. Use files you have the right to use: your own designs, open-hardware projects (many publish KiCad or EAGLE files), or documentation you are licensed to use.

Can I use it next to OpenBoardView or FlexBV?

Yes. On Windows TRACE is a portable EXE with no installer, and on Linux the AppImage installs nothing, so it does not interfere with other boardviewers. See the comparison for what each one does best.
