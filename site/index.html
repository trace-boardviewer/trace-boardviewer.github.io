What is a boardviewer?

A boardviewer shows where every part, pin and net sits on a printed circuit board, so you can go from a fault on the schematic to the exact pad to probe. TRACE is a free, open-source boardviewer that keeps the board, its schematic and its PDF datasheets in one window and searches all of them at once. It opens .brd files (EAGLE, selected TestLink/Landrex and TOPTEST exports, and native Allegro layouts), EAGLE boards and schematics, .bvr boardviews, GenCAD .cad/.gcd and KiCad boards and schematics. New to it? The getting started guide walks through a first repair session. Coming from OpenBoardView or FlexBV? See the honest comparison.

What it does

  • Board: search by reference, value, package or net; net highlighting; pin and part inspection; top and mirrored bottom; zoom, pan, rotate; two-point measurement in mm.
  • Schematic: KiCad, EAGLE and Altium SchDoc with connectivity; exact board↔schematic matching; unmatched or ambiguous parts are listed, never guessed.
  • Documents: offline PDF search and page notes, plus English text recognition for scanned pages with confidence marks and Cancel; PNG/JPEG/WebP/SVG images with calibrated measurement; documents are remembered per board.
  • Notes: per part or named pin, with measured voltage/resistance and a migration backup; unresolved notes stay visible.
  • Import: more board readers, ODB++ product models and a single board with companions opened directly from a ZIP; progress and Cancel, background search and a local format diagnostic report. The table below states each reader's validation scope.
  • Private: your boards and files stay on your computer; no account, no telemetry, and board files are read without modification. FZ/CAE can open with published default keys; session-key entry can be skipped. Network settings show optional update checks and explicit support-receipt verification.
  • Support: reminders at startup and hourly are optional. A provider-confirmed Stripe or Ko-fi payment hides the reminder and heart for one calendar year, including offline use.
  • Interface: English, French, German, Hungarian, Italian, Polish, Slovak, Ukrainian; dark/light; Workshop and Focus layouts. Ctrl+O open, Ctrl+F search, F fit, R rotate, M measure.

macOS — experimental

The experimental 1.3.1 build is for Apple silicon Macs only (M1 or later) and is ad-hoc signed but not notarized. Native validation of this published package is pending. macOS blocks a downloaded copy until you allow it once: right-click the app and choose Open, or clear the quarantine flag in Terminal:

xattr -dr com.apple.quarantine "/Applications/TRACE Boardviewer.app"

Intel Macs are not supported. See the release notes for the current validation status.

Questions

Does it send my boards anywhere?

Board and schematic files are processed on your computer. Bug reports go to a separate receiver only after you review and choose Send; no GitHub account is needed. Your description may contain paths or token-like text, so check it before sending. The optional technical summary uses closed fields for version, platform, architecture, locale, surface and import type; these fields cannot contain local paths. No board files or attachments are sent. Drafts and retry records expire after seven days; expired records are removed the next time you access bug reports. A local helper flags possible paths and token-like text in your description and removes selected text only if you choose to remove it. There is no account or telemetry. Other optional network features are a stable-release check on GitHub and payment verification when you choose Verify payment. Verification sends only the app's random support reference to the receipt service. Settings lists allowed hosts and a clearable request log. Updates are never downloaded or installed automatically. Payment buttons open Stripe or Ko-fi in your browser; support and verification can both be skipped.

My BRD / BDV / FZ does not open.

Check the table above; some families are still draft. Open an issue with the family, file size and the exact diagnostic — never upload a file you may not share.

Is there a Linux version?

Yes. Stable 1.3.1 includes experimental unsigned .deb and AppImage packages for x86-64. Native acceptance testing of these published packages is pending. See the Linux downloads and the Linux page.

Where do I get board files?

TRACE does not include or link to board files. Use files you have the right to use: your own designs, open-hardware projects (many publish KiCad or EAGLE files), or documentation you are licensed to use.

Can I use it next to OpenBoardView or FlexBV?

Yes. On Windows TRACE is a portable EXE with no installer, and on Linux the AppImage installs nothing, so it does not interfere with other boardviewers. See the comparison for what each one does best.
