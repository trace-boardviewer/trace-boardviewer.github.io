Choosing a boardviewer

TRACE details refer to stable version 1.3.3, published 12 October 2026. Updated: 13 October 2026.

Choose a boardviewer by the files you actually have. This page explains what TRACE covers and where to check other programs. It does not restate the prices, versions or formats of other programs.

Other boardviewers change their prices, platforms, formats and licences. This page makes no claim about them. Check each program's own website or source repository before you choose one. Product names are trademarks of their owners; TRACE is not affiliated with any of them.

What TRACE covers (1.3.3)

  • Price and licence: free, MIT-licensed open source. No account and no telemetry.
  • Windows x64: a portable EXE, not code-signed. Nothing is installed.
  • macOS (Apple silicon, macOS 13 or later) and Linux (x86-64): experimental and unsigned. Native acceptance of 1.3.3 on both platforms is still pending.
  • Board formats: the generated format table lists every reader, its variants and its limits. See the EasyEDA Pro guide for .epro2 and archive limits, and the ODB++ guide for archive and copper scope. Some readers are drafts, and some are checked only with selected real files.
  • Schematics and PDFs: KiCad and EAGLE schematics, Altium SchDoc and PDF datasheets, searched offline, with cross-probing to the board. Scanned PDF pages can be read with bundled English text recognition, started by you for each page, with a limit of 40 megapixels and 120 seconds per page.
  • Notes: per part and per pin, including a voltage or resistance you measured. Notes follow the board file by its content hash, so renaming the file keeps them.
  • Network: an optional update check (off until you choose; the first start asks once, and Settings changes the choice) and, only when you choose them, support verification and bug reports. Settings > Network lists each network feature, its host and a request log.

Limits you should know

  • Some readers are drafts or have limited validation. XZZ, HyperLynx, Fabmaster FATF, EasyEDA Standard and CSV/TSV pin lists rely on synthetic checks. Other readers are checked against selected real exports only. Check your file's variant in the format table.
  • Native Allegro has layout limits. Selected documented layouts import parts, nets, pads and outlines. Unknown records, older databases and unverified layer semantics are refused with an explanation.
  • Experimental builds. The macOS and Linux builds are experimental and unsigned. See the native acceptance note above.
  • Unsigned Windows EXE. SmartScreen may show a warning. The portable download is about 5% smaller than in 1.3.1. Each launch unpacks the app into a private temporary folder, which is removed on normal exit.
  • Size and format limits. Most readers have a 64 MiB input limit. Native Allegro databases allow up to 240 MiB when they declare 4,000,000 objects or fewer. Each reader has its own limits; unsupported or damaged files are refused with an explanation rather than guessed.
  • Copper detail. ODB++ imports draw copper pads, lines, arcs and drilled holes; copper pours and text are not read. Other boardview and PCB readers do not show routed tracks, zones or vias. Net highlighting is a logical connection guide, not a copper-trace inspection.

Other boardviewers

Other boardview projects exist. For current primary-source information, see the OpenBoardView source repository and releases and the NexusBV project site. This page does not rank products or make claims about their current prices, platforms or file coverage; compare their published format lists with the exact file variant you have.

Choose by the job in front of you

  1. You need to edit the design, route copper, run design-rule checks or generate manufacturing files. Use the design application and project that own the board. KiCad's official PCB Editor manual documents editing and DRC; Altium's official design-tool documentation describes its native project formats and integrations. TRACE is a read-only viewer and does not replace those design workflows.
  2. You have an existing PCB or boardview and need to inspect it with its schematic, PDF and notes. Check the format table for the exact extension, variant, validation level and limits. Open a copy first, then verify a few known references, nets and dimensions against a trusted source before relying on the view.
  3. You have a boardview with a separate schematic. Attach a supported KiCad, EAGLE or Altium schematic and compare exact component/net names. TRACE lists unmatched or ambiguous links rather than guessing. For Altium project hierarchy, keep sibling .SchDoc sheets and the .PrjPcb file together; see the Altium guide.
  4. You have only a PDF schematic or a board image. TRACE can search PDF text offline; scanned pages need the optional English OCR. A PDF or image is a document, not a board or netlist, and measurements on an image require calibration.
  5. You need routed copper geometry. Use an ODB++ file for the copper objects TRACE currently displays; the support table describes the remaining ODB++ scope. Most other readers provide pads, components and logical net highlighting without routed tracks.
  6. You plan to use macOS or Linux. Those 1.3.3 packages are experimental and unsigned; check the Linux page or the download notes before choosing a package.
